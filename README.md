# Sunset Kart

Оригинальная браузерная 3D-карт-гонка на HTML, CSS и JavaScript / Three.js. Без ассетов Nintendo, регистрации и серверной части. Трасса, карты, гонщики и окружение строятся программно.

## Запуск

```sh
npm ci
npm run dev
```

Откройте адрес сервера в браузере. Для Android используйте актуальный Chrome с WebGL; телефон и сервер должны находиться в одной сети. Для публикации выполните `npm run build` и разместите содержимое `dist/` на статическом хостинге. Открытие исходного HTML через `file://` не поддерживается: используются ES-модули.

## Игра

- Автоматический газ, 3 круга, 5 компьютерных соперников.
- Стрелки или A/D — руль, Shift — дрифт (резче поворот, ниже скорость), пробел — нитро, Esc — пауза.
- На сенсорных устройствах доступны экранные кнопки с одновременным нажатием.
- Монеты пополняют нитро. Обочина и столкновения замедляют карт.
- При потере фокуса игра автоматически ставится на паузу.
- Звук включается отдельной кнопкой; по умолчанию выключен.

`npm test` проверяет правила гонки, `npm run build` — production-сборку. Шрифты Google Fonts необязательны: при отсутствии сети используются системные. Игровые зависимости входят в сборку.

Для headless-проверки без GPU используйте программный WebGL:

```sh
agent-browser --session kart --args '--no-sandbox,--disable-gpu-sandbox,--use-gl=angle,--use-angle=swiftshader-webgl,--enable-unsafe-swiftshader,--disable-vulkan' open http://127.0.0.1:3000
```

Эти параметры нужны только проверочному браузеру в изолированном контейнере, не браузеру игрока.
